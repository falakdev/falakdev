# Falak Shair — Professional Dashboard

This repository contains a simple professional dashboard / personal display page for Falak Shair.

Files added:
- `index.html` — the dashboard page (edit to add your details)
- `styles.css` — styles used by the page

How to update
1. Edit `index.html` in this repository to change text, links, and sections.
2. Commit your changes and they will appear in the repository.

Publish with GitHub Pages
1. In the repository on GitHub, go to Settings → Pages.
2. Under "Source", choose "Deploy from a branch" and select the `main` branch and `/ (root)` folder.
3. Save — the site will be available at `https://falakdev.github.io/` once deployed.
